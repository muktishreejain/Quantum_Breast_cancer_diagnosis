# Adaptive Ensemble-Guided Hybrid Quantum-Classical Framework for Breast Cancer Diagnosis

This project implements a research-oriented hybrid pipeline for breast cancer diagnosis using an adaptive classical-to-quantum routing strategy on the Wisconsin Breast Cancer Dataset.

The framework combines uncertainty-aware classical ensemble learning with selective quantum refinement in order to improve prediction reliability on diagnostically difficult tumor samples while maintaining computational feasibility on a standard laptop.

The complete project methodology and chapter-level implementation details are aligned with the submitted project report structure. 

---

## Overview

The framework combines:

* A **three-model classical ensemble**:

  * `RandomForestClassifier`
  * `LogisticRegression`
  * `GradientBoostingClassifier`
* A **Variational Quantum Classifier (VQC)** for uncertain cases only
* An **adaptive ambiguity score + threshold sweep** to optimize routing behavior

All experiments are designed to remain laptop-friendly while preserving methodological rigor.

---

## Project Motivation

Classical machine learning models provide strong performance on clearly separable benign and malignant breast tumor samples, but they may produce unstable confidence estimates on borderline cases.

Instead of applying expensive quantum classification on the full dataset, this project investigates a more practical question:

> Can quantum machine learning be invoked only when a diverse classical ensemble becomes uncertain?

This selective hybrid philosophy allows the framework to:

* preserve computational efficiency,
* reduce unnecessary quantum simulation,
* and still refine difficult predictions through a quantum model.

## Methodology

---

### 1) Data and Feature Processing

* Input: Wisconsin Breast Cancer dataset (`data.csv`)
* Label mapping:

  * `M -> 1` (malignant)
  * `B -> 0` (benign)

Preprocessing pipeline:

* Standardization with `StandardScaler`
* PCA reduction from **30 features to 4 features**

Train/test split:

* `test_size = 0.2`
* `stratify = y`
* `random_state = 42`

The PCA reduction is necessary to maintain compatibility with the 4-qubit quantum circuit used in the VQC. 

---

### 2) Classical Ensemble Predictions

Three independent classical classifiers are trained on the PCA-reduced feature space:

* Random Forest
* Logistic Regression
* Gradient Boosting

For each test sample, the framework stores:

* `rf_pred`, `rf_conf`
* `lr_pred`, `lr_conf`
* `gb_pred`, `gb_conf`

where each confidence is the maximum class probability generated by the corresponding classifier.

For non-ambiguous samples, the final classical decision is computed by **majority vote** across RF/LR/GB.

---

### 3) Ambiguity Score Engine

For every test sample:

* `average_confidence = mean([rf_conf, lr_conf, gb_conf])`
* `confidence_variance = variance([rf_conf, lr_conf, gb_conf])`

The ambiguity score is computed as:

**ambiguity_score = alpha * (1 - average_confidence) + beta * confidence_variance**

with:

* `alpha = 0.6`
* `beta = 0.4`

Higher ambiguity score indicates higher diagnostic uncertainty.

This ambiguity engine replaces the traditional single-model fixed-confidence routing used in simpler hybrid systems.

---

### 4) Adaptive Threshold Optimization

Instead of relying on one manually selected threshold, the framework performs an adaptive sweep across:

```python
threshold_values = [0.02,0.04,0.06,0.08,0.10,0.12,0.14,0.16,0.18,0.20]
```

For each threshold:

1. Route samples with `ambiguity_score > threshold` to the quantum stage.
2. Train a fresh VQC on ambiguous training samples only.
3. Predict ambiguous test samples with VQC.
4. Retain majority-vote classical predictions for non-ambiguous test samples.
5. Compute final hybrid metrics.

The best threshold is selected by maximum hybrid diagnostic accuracy.

---

### 5) Quantum Model (Preserved Core)

The Variational Quantum Classifier uses:

* `ZZFeatureMap(feature_dimension=4, reps=1)`
* `RealAmplitudes(num_qubits=4, reps=1)`
* `COBYLA(maxiter=100)`
* Aer simulator backend via `qiskit_aer`

The VQC is intentionally shallow and lightweight to ensure simulation feasibility on classical hardware.

## Key Observations

The threshold sweep reveals a clear uncertainty-performance tradeoff:

* very low thresholds route too many samples to quantum classification and reduce stability,
* very high thresholds underutilize the VQC,
* a moderate threshold of **0.14** provides the best balance.

This demonstrates that:

> selective quantum invocation is more effective than indiscriminate quantum application.

---

## Challenges Faced During Implementation

### 1. Quantum Simulation Overhead

Each threshold iteration requires a fresh Variational Quantum Classifier training cycle, making repeated simulation computationally expensive.

### 2. Qubit Dimensionality Restriction

The original dataset contains 30 medical features, but the VQC supports only a 4-qubit input representation. PCA reduction was therefore mandatory.

### 3. Threshold Sensitivity

Hybrid performance changed noticeably depending on the ambiguity threshold, requiring careful tuning to avoid both quantum overuse and quantum underuse.

### 4. Strong Classical Baselines

Standalone Logistic Regression performed exceptionally well on this dataset split, making hybrid superiority difficult to demonstrate without efficient selective routing.

### 5. Environment Compatibility

Stable execution required controlled installation of older Qiskit Machine Learning dependencies within a Python 3.10 virtual environment.
